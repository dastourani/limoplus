# قالب فایل محتوای لیمو پلاس

هر **فصل** یک فایل Markdown است (پسوند `.md`). اگر فصل عکس دارد، فایل و پوشه‌ی `images` را با هم در یک
فایل ZIP بگذارید. نمونه‌ی کامل: پوشه‌ی `content/samples/math-1`.

```
01-limits/
├── chapter.md
└── images/
    └── limit-hole.svg
```

بارگذاری: پنل مدیر › محتوا › «بارگذاری فصل از فایل». اول «فقط بررسی» را بزنید؛ اگر خطایی نبود «بارگذاری».
اگر همان فصل را دوباره بارگذاری کنید، **به‌روز می‌شود** و پیشرفت و آمار کاربران حفظ می‌شود.

## ۱. مشخصات فصل (اول فایل، بین دو خط `---`)

```
---
شناسه-کتاب: math-1
کتاب: ریاضی عمومی ۱
قیمت-کتاب: 249000
رشته‌ها: economics, biomedical-engineering
شناسه-فصل: limits
فصل: 1
عنوان: حد و پیوستگی
رایگان: بله
---
```

| کلید | لازم؟ | توضیح |
| --- | --- | --- |
| `شناسه-کتاب` | بله | شناسه‌ی ثابت کتاب، لاتین، بدون فاصله. همه‌ی فصل‌های یک کتاب همین را دارند. |
| `کتاب` | بله | نام کتاب |
| `قیمت-کتاب` | خیر | تومان؛ کافی است در یکی از فصل‌ها بیاید |
| `رشته‌ها` | بله برای کتاب جدید | شناسه‌ی رشته‌ها (از پنل مدیر › رشته‌ها)، با کاما جدا |
| `شناسه-فصل` | بله | شناسه‌ی ثابت فصل |
| `عنوان` | بله | عنوان فصل |
| `رایگان` | خیر | `بله` یعنی کل این فصل نمونه‌ی رایگان است |

**شناسه‌ها را هیچ‌وقت عوض نکنید.** با شناسه است که سیستم می‌فهمد این همان فصل/بخش/تست قبلی است.
شناسه‌ی بخش‌ها، تست‌ها و فلش‌کارت‌ها باید **در کل کتاب** یکتا باشد (نه فقط در یک فصل). اگر بخشی یا تستی را به
فصل یا بخش دیگری ببرید و شناسه‌اش را نگه دارید، همان مورد جابه‌جا می‌شود و آمار و پاسخ‌های کاربران حفظ می‌شود.

## ۲. بخش‌ها

هر بخش با یک تیتر `##` شروع می‌شود. شناسه‌ی ثابت داخل `{# }` می‌آید:

```
## مفهوم حد {#limit-idea}
متن جزوه…
```

متن زیر تیتر، **حالت جزوه** است. برای **حالت خلاصه** یک بلوک خلاصه بگذارید:

```
:::خلاصه
- نکته‌ی کوتاه اول
- نکته‌ی کوتاه دوم
:::
```

## ۳. نوشتن متن

- فرمول درون‌خطی: `$x^2$` · فرمول در خط جدا: `$$\frac{a}{b}$$` (LaTeX)
- پررنگ: `**متن**` · فهرست: `- مورد`
- جدول: جدول معمولی Markdown (حداکثر ۴ یا ۵ ستون)
- عکس: `![زیرنویس عکس](images/نام-فایل.svg)` — اسم فایل لاتین، بدون فاصله. SVG برای نمودار، JPG/PNG برای عکس.
  هر عکس حداکثر ۵ مگابایت؛ SVG نباید اسکریپت داشته باشد.
- کادرها:

```
:::نکته
…
:::

:::تله
…
:::
```

انواع کادر: `نکته`، `تله`، `هشدار`، `مثال`. بلوک‌ها داخل هم نمی‌روند و هر بلوک با یک خط `:::` بسته می‌شود.

## ۴. تست

```
:::تست {#q-sin3x}
منبع: کنکور ارشد اقتصاد ۱۴۰۱، سؤال ۲۳
سطح: آسان
حوزه: عمومی
نوع: محاسباتی
زمان: 30
صورت:
حاصل $\lim_{x \to 0} \frac{\sin 3x}{x}$ کدام است؟
- [ ] $0$
- [ ] $1$
- [x] $3$
- [ ] $\frac{1}{3}$
توضیح: پاسخ تشریحی کامل (می‌تواند چند خط باشد).
راه‌حل سریع: میانبر تستی (اختیاری).
زاویه‌ی دیگر: یک راه یا دید متفاوت (اختیاری).
فلش‌کارت: sin-limit, equivalents
:::
```

| فیلد | لازم؟ | مقدارها |
| --- | --- | --- |
| شناسه `{#…}` | توصیه می‌شود | ثابت؛ بدون آن، با جابه‌جا شدن ترتیب تست‌ها آمارشان قاطی می‌شود |
| `منبع` | بله | «نام کنکور + سال»، با «، سؤال N» اختیاری؛ یا `تألیفی`. چند خط منبع مجاز است. |
| `سطح` | بله | آسان، متوسط، سخت |
| `حوزه` | خیر | عمومی، تخصصی |
| `نوع` | خیر | حفظی، مفهومی، محاسباتی، تحلیلی |
| `زمان` | خیر | ثانیه |
| `صورت` | بله | متن سؤال؛ تا اولین گزینه ادامه دارد |
| گزینه‌ها | بله | ۲ تا ۶ گزینه، دقیقاً یکی با `[x]` |
| `توضیح` | بله | پاسخ تشریحی |
| `راه‌حل سریع`، `زاویه‌ی دیگر` | خیر | |
| `فلش‌کارت` | خیر | شناسه‌ی فلش‌کارت‌های مرتبط در همین فایل |
| `رایگان` | خیر | `بله` = این تست حتی در فصل پولی رایگان است |

## ۵. فلش‌کارت

فلش‌کارت **نکته** است، نه سؤال: رو = عنوان، پشت = نکته.

```
:::فلش‌کارت {#sin-limit}
عنوان: حد معروف سینوس
نکته: نزدیک صفر، سینوس و زاویه (رادیان) تقریباً برابرند.
فرمول: \lim_{x\to 0}\frac{\sin x}{x}=1
:::
```

فرمول فلش‌کارت **بدون** علامت `$` نوشته می‌شود.

## ۶. وقتی چیزی را حذف می‌کنید

اگر بخش، تست یا فلش‌کارتی در نسخه‌ی جدید فایل نباشد، **بایگانی** می‌شود (از اپ پنهان می‌شود ولی پاک نمی‌شود)
و اگر دوباره با همان شناسه برگردد، با همه‌ی آمارش برمی‌گردد.

## دستور آماده برای هوش مصنوعی

این متن را همراه با این راهنما به هوش مصنوعی بدهید:

> تو نویسنده‌ی محتوای آموزشی «لیمو پلاس» هستی. یک فصل از کتاب «[نام کتاب]» درباره‌ی «[موضوع فصل]» برای
> دانشجویان رشته‌ی «[رشته]» بنویس، دقیقاً در قالبی که در راهنمای پیوست آمده (یک فایل chapter.md).
>
> - شناسه‌ها: شناسه-کتاب «[…]»، شناسه-فصل «[…]»، رشته‌ها «[…]». برای هر بخش، تست و فلش‌کارت یک شناسه‌ی
>   لاتین کوتاه و معنادار بگذار.
> - ۳ تا ۵ بخش؛ هر بخش متن جزوه‌ی کامل و روان، به‌علاوه‌ی یک بلوک «خلاصه» با ۳ تا ۵ نکته‌ی کوتاه.
> - متن را با بیان خودت بنویس؛ از متن یا شکل کتاب مرجع کپی نکن.
> - همه‌ی فرمول‌ها LaTeX، درون‌خطی با `$` و جدا با `$$`.
> - برای هر بخش ۲ تا ۴ تست چهارگزینه‌ای با «سطح»، «حوزه»، «نوع»، «توضیح» کامل و در صورت امکان
>   «راه‌حل سریع». جای گزینه‌ی درست را متنوع کن. اگر تست از کنکور واقعی نیست، منبع را «تألیفی» بنویس؛
>   هرگز منبع کنکور از خودت نساز.
> - برای هر بخش ۲ تا ۳ فلش‌کارت نکته‌ای (نه سؤالی)، و هر تست را به فلش‌کارت مرتبطش وصل کن.
> - هر جا «تله‌ی تستی» رایجی هست، یک کادر `:::تله` بگذار.
> - فقط محتوای فایل را بنویس، بدون توضیح اضافه.

بعد از تولید: فایل را در پنل با «فقط بررسی» چک کنید، و **درستی علمی و جواب تست‌ها را خودتان یا یک ویراستار
بازبینی کنید**؛ بررسی خودکار فقط قالب را می‌سنجد، نه درستی علمی را.
