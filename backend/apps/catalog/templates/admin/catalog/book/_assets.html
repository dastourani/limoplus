{% load static %} {% comment %} The panel's stylesheet and scripts, with the file's own modification time as a version. Without it a browser keeps the old panel.css after a change and the panel looks broken in a way the server cannot see («the width buttons do nothing» was exactly that for one round: the JS was new, the CSS was from the cache). A file's mtime is enough for a dev server and harmless on the server: the value changes only when the file does. {% endcomment %}
