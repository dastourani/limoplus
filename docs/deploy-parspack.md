# راه‌اندازی سرور لیموخوان روی پارس‌پک (PaaS)

پارس‌پک کد را از شاخه‌ی `main` گیت‌هاب برمی‌دارد و با هر push به `main` خودش دوباره دیپلوی می‌کند.
پس **هر ادغام در `main` یعنی تغییر فوری سرور واقعی.**

## ۱. ترتیب کار (یک‌بار)

1. **پایگاه داده‌ی PostgreSQL** را در پنل پارس‌پک بسازید (سرویس دیتابیس، کنار همین برنامه).
   آدرس اتصالش را به این شکل در متغیر `DATABASE_URL` بگذارید:
   `postgres://نام‌کاربر:رمز@آدرس-دیتابیس:5432/نام-دیتابیس`
2. **دیسک ماندگار (Volume)** بسازید و به برنامه وصل کنید، با مسیر `/opt/app-root/data`.
   عکس‌ها و فایل‌های آپلودی آنجا می‌مانند؛ هر چیز دیگری داخل کانتینر با هر دیپلوی پاک می‌شود.
3. متغیرهای بخش ۲ را در پنل برنامه تنظیم کنید.
4. PR را در `main` ادغام کنید. دیپلوی خودکار شروع می‌شود.
5. وقتی بالا آمد، در ترمینال برنامه یک‌بار مدیر بسازید:
   `python manage.py createsuperuser`
6. پنل را در `https://دامنه/ADMIN_URL/` باز کنید.

## ۲. متغیرهای پنل پارس‌پک

| متغیر | مقدار | توضیح |
|---|---|---|
| `SECRET_KEY` | رشته‌ی تصادفی بلند | برنامه فقط همین نام را می‌خواند (نه `DJANGO_SECRET_KEY`). |
| `HASH_KEY` | رشته‌ی تصادفی بلند دیگر | فقط یک‌بار. عوض شود همه از حساب خارج می‌شوند. |
| `DEBUG` | `False` | روی سرور واقعی همیشه False. |
| `SITE_DOMAIN` | دامنه‌ی سرور، بدون https | مثلاً `api.limookhan.ir` |
| `ALLOWED_HOSTS` | همان دامنه (با کاما اگر چندتاست) | |
| `CSRF_TRUSTED_ORIGINS` | `https://` + دامنه | |
| `ADMIN_URL` | چیزی که فقط خودتان می‌دانید | مثلاً `manage-7f3k` |
| `DATABASE_URL` | آدرس PostgreSQL | خالی = SQLite = پاک شدن داده با هر دیپلوی |
| `MEDIA_ROOT` | `/opt/app-root/data/media` | روی دیسک ماندگار |
| `SERVE_MEDIA` | `True` | چون nginx جلوی برنامه نیست |
| `SMS_BACKEND` | `raygan` | با `DEBUG=False`، مقدار `console` پذیرفته نمی‌شود |
| `RAYGAN_USERNAME`، `RAYGAN_PASSWORD`، `RAYGAN_SENDER_NUMBER` | از پنل رایگان اس‌ام‌اس | |
| `PAYMENTS_ENABLED` | `False` تا رسیدن مرچنت واقعی | خرید پیام «به‌زودی» می‌دهد |
| `ZIBAL_MERCHANT` | کد مرچنت واقعی (بعداً) | وقتی آمد، `PAYMENTS_ENABLED` را True کنید |
| `TRUSTED_PROXY_COUNT` | `1` | پراکسی پارس‌پک جلوی برنامه |
| `DISABLE_COLLECTSTATIC` | `1` | هنگام ساخت اجرا نشود؛ `app.sh` موقع شروع انجامش می‌دهد |
| `DISABLE_MIGRATE` | `1` | همین‌طور |
| `WEB_CONCURRENCY` | `2` | تعداد پردازش‌های هم‌زمان |

`DJANGO_SECRET_KEY` لازم نیست؛ مقدارش را در `SECRET_KEY` بگذارید و آن را پاک کنید.
`CORS_ALLOWED_ORIGINS` فقط وقتی لازم است که نسخه‌ی وب اپ روی دامنه‌ی دیگری باشد.

## ۳. هر بار شروع برنامه

پارس‌پک فایل `backend/app.sh` را اجرا می‌کند:
`migrate` (تغییرات دیتابیس) ← `collectstatic` (فایل‌های پنل و سایت) ← `gunicorn` روی پورت 8000.
اگر برنامه بالا نیامد، اولین جای نگاه **لاگ برنامه** در پنل پارس‌پک است؛ چند خط آخرش را برای Claude بفرستید
(اگر رمزی در آن بود، پوشانده).

اگر بعد از `DEBUG=False` سایت مدام به خودش برگشت (حلقه‌ی redirect) یا پارس‌پک برنامه را «ناسالم» دانست،
متغیر `SECURE_SSL_REDIRECT=False` را بگذارید (HTTPS را خود پارس‌پک می‌دهد). پورت برنامه در پنل باید 8000 باشد.

## ۴. پیش از هر ادغام در `main`

- از دیتابیس پشتیبان بگیرید (پنل دیتابیس پارس‌پک).
- PR باید تست‌هایش سبز باشد.

## ۵. هنوز مانده

- نسخه‌ی وب اپ (`WEBAPP_DIR`) روی این سرور نیست؛ فعلاً ریشه‌ی سایت پیام «نسخه‌ی وب اپ هنوز اینجا نیست» می‌دهد.
- عکس‌های محتوای پولی هنوز با آدرسشان برای همه باز است (کار «پیش از انتشار»).
